Navbar Walkthrough

Read a navbar before you build one.

A navbar is one of the first things people notice on a page — and one of the easiest things to copy without understanding. It is not just a row of links.

This walkthrough slows the copying down. You inspect real navbars, question what an AI generates, write a design spec, then change the code yourself. Every part has a playground you can touch.

            Only after the plan exists do you write the prompt:
          

          
Create simple HTML for a navbar for a game studio.
The brand name is ZS One. The links are Games, Studio, News, Support.
The most important link is Play Now. Keep the code beginner-friendly
and explain the structure.


          

            Plan beats prompt. When you already know the answer you want,
            you can tell when the AI hands you something worse.

          Part 05
          
Write a design spec

          

            Before styling, write the decisions down: background, text color,
            font, link spacing, border or shadow, padding, and the overall feel.
            A spec keeps the AI — and you — honest.
          


          
// design spec — ZS One navbar
background     : #1D3E60   (deep navy)
text color     : #FFFFFF on the bar
font           : Inter — clean and highly readable
link spacing   : 16-24px between links
border         : 3px solid #D23B36 along the bottom
padding        : 12px top / bottom, 18px on the sides
overall feel   : clean, bold, confident


          

            Feel drives the numbers. "Confident game studio" is why the
            bar is a solid navy with a sharp red edge — not a timid gray line.

          Part 08
          
Hover and states

          

            A navbar should respond when someone points at a link. Pick an
            effect, hover the link, and read the exact CSS that produces it.

            Why react to a hover? A hover response is feedback — it
            confirms the link is clickable and that you are aimed at the right
            one. It reduces mis-clicks and makes the page feel alive. Without
            it, links read as flat, dead text and people are unsure what is
            interactive.
          

        


        
        

          Part 09
          
What you learned

          

            You restructured a plain row into a navbar, inspected each part's
            job, saw the links are just a list, planned before prompting,
            questioned the AI's answer, wrote a spec, painted it, and made it
            react to a hover.
          

          

            The habit matters more than this one navbar:
            look before you build, plan before you prompt, and decide for
              yourself which lines to keep.
