Read it once, fully. The rule: 38°C or above is a Heat Warning, 15°C up to 37°C is Pleasant, anything below 15°C is a Cold Alert.

temps = [42, 28, 12, 35, 8, 39, 20] for temp in temps: if temp >= 38: print("Heat Warning") elif temp >= 15: print("Pleasant") else: print("Cold Alert")

Skill 5 — Compare

Two correct solutions — which would you pick?

Both of these classify correctly today. They behave differently if the rules ever change.

if / elif / else chain

if temp >= 38: print("Heat Warning") elif temp >= 15: print("Pleasant") else: print("Cold Alert")

Three independent ifs

if temp >= 38: print("Heat Warning") if 15 <= temp < 38: print("Pleasant") if temp < 15: print("Cold Alert")
