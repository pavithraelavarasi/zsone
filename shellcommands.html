🌿 Shell Learning Adventure

Find the ZS2028 treasure

In this activity, you will navigate through 5 zones using terminal commands. Each zone teaches you one new command. Inside every zone, a clue word is hidden. Find it, collect all four words, and combine them to reveal the secret phrase. Once you find it, write it into a file and place that file inside a folder named after you.

For this assignment you need to connect to a remote server machine and perform all the operations there. To connect to the server, there is a specific command you need to use. You can learn that command from Zone 1.

ssh ls cat cd grep mkdir mv

Commands unlock as you complete each zone
