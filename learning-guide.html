Learning Guide

Conditionals, For Loops & Lists

An if/elif/else makes a decision. A for loop repeats it. A list gives it something real to repeat over. Learn them in that order, then see all three combined.

Concept: if / elif / else Concept: for loop Concept: lists Difficulty: Beginner

Start here

Decisions, then repetition, then data

Three ideas, in the order you'll actually use them: decide once, repeat that decision, then apply it to a real list of values.

Before there's anything to repeat, there's a decision to make. A conditional runs different code depending on whether something is true.

score = 45 if score >= 40: print("Pass") else: print("Fail")

if / else — two-way

Exactly one of the two branches runs, every time.

if score >= 40: print("Pass") else: print("Fail")

if / elif / else — three-way (or more)

elif only gets checked if everything above it was false. Order matters — the most specific condition goes first.

if temp >= 38: print("Heat Warning") elif temp >= 15: print("Pleasant") else: print("Cold Alert")

Exactly one branch runs

Python checks top to bottom and stops at the first true condition — the rest are skipped, even if they'd also be true.

else is optional

You can have if alone, or if/else, with no elif at all — add branches only when you need them.

Indentation marks the branch

Whatever's indented under if belongs to that branch. A line back at the if's level is outside it.

A for loop repeats a block of code once for every item in a sequence. The simplest sequence to start with is a range of numbers.

for i in range(1, 6): print(i)

This prints 1 2 3 4 5. range(1, 6) counts from 1 up to 6 — the second number is never reached.

A list holds many values in one variable, in a fixed order. Instead of score1, score2, score3..., you get one name for the whole collection:

scores = [45, 32, 78, 40, 55, 21, 90]

Creating a list

Square brackets, values separated by commas: [45, 32, 78]. Order is preserved — the first value stays first.

Indexing

Every item has a position, starting at 0, not 1. scores[0] is the first item.

len()

len(scores) gives you the count of items — how many positions there are to visit.

Picture it

Each box below is one item in scores. The number underneath is its index.

scores[0] is 45 · scores[3] is 40 · scores[6] is the last item, at index len(scores) - 1

Reading from a list

print(scores[0]) # 45 — the first item print(scores[3]) # 40 print(len(scores)) # 7 — there are 7 items

Iterating a list with a loop

Here's where the last two tabs meet a real container. A for loop can walk through scores directly, one item at a time — no index needed at all:

for score in scores: print(score)

Each time round, score is reassigned to the next value in the list — first 45, then 32, and so on — until every item has been visited once. That's the whole loop, with the indexing handled for you.

Combine them

Loop + condition, two shapes you'll keep seeing

Both of these are a for loop with a decision inside it. The number of branches is the only real difference.

Two-way split — counting

pass_count = 0 fail_count = 0 for score in scores: if score >= 40: pass_count += 1 else: fail_count += 1 print(f"Passed: {pass_count}, Failed: {fail_count}")

This is the shape behind Read the Code: Pass/Fail Counter.

Three-way split — classifying

for temp in temps: if temp >= 38: print("Heat Warning") elif temp >= 15: print("Pleasant") else: print("Cold Alert")
